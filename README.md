# @norton-tanzarella/cms-contract

Zod schemas, page registry and `zodToFieldMeta` for the Norton Tanzarella headless CMS.

## Setup

```bash
pnpm install
pnpm build
```

## Local link

```bash
pnpm link --global
cd ../norton-tanzarella-backend && pnpm link --global @norton-tanzarella/cms-contract
```

Or use `file:../norton-tanzarella-cms-contract` in `package.json`.
